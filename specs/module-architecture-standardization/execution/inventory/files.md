## Structural Observations

| Module | Has `service/` | Has proper `application/` | Has proper `domain/` | Has `infra/database/` | Has `infra/messaging/` | Has `infra/workers/` | Has `presentation/controllers/` |
|---|---|---|---|---|---|---|---|
| agent | no | yes | yes | yes | yes | yes | yes |
| billing | yes (use_cases, dtos) | yes (composers only) | yes | flat `infra/` | no | yes (registry) | yes |
| core | yes (use_cases, dtos) | yes (composers, dependencies) | yes | flat `infra/` | no | no | yes |
| identity | yes (use_cases, dtos) | yes (composers) | yes | flat `infra/` | no | yes (registry) | yes |
| metering | yes (use_cases, dtos) | yes (composers) | yes | flat `infra/` | no | yes (registry) | yes |
| observability | yes (use_cases, dtos) | yes (composers) | yes | flat `infra/` | no | yes (registry) | yes |
| tools | yes (use_cases, dtos, tool_converter) | yes (composers) | yes | flat `infra/` | no | yes (registry) | yes |

## Gaps vs Canonical Structure

- All non-agent modules have `service/` directory instead of canonical `application/use_cases` and `application/dtos` files.
- All non-agent modules have flat `infra/` (models.py, repositories.py, mappers.py) instead of canonical `infra/database/` subdirectory.
- All non-agent modules lack `infra/messaging/` subdirectory (consumers.py, event_mappers.py, publishers.py).
- All non-agent modules lack `domain/events.py`, `domain/services.py`, `domain/value_objects.py`.
- Only agent and tools have `presentation/mappers.py`.
