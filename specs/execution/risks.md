# MVP migration and runtime risk register

- **critical** — cross-tenant data exposure. Evidence: private resources under `src/modules/` must pass shared tenancy authorization.
- **critical** — API-key execution against the wrong project. Evidence: runtime principals are resolved in `src/shared/security/`.
- **critical** — provider or project secrets in logs. Evidence: redaction is applied in security and HTTP tool adapters.
- **high** — duplicate Outbox publication. Mitigation: unique idempotency keys and claim-based dispatch.
- **high** — duplicate Inbox processing. Mitigation: persisted message and idempotency uniqueness before acknowledgement.
- **high** — partial state without matching event. Mitigation: state and Outbox writes share the module UnitOfWork transaction.
- **high** — refresh-token replay. Mitigation: hashed sessions, rotation, revocation and replacement ForeignKey lineage.
- **high** — SSRF through HTTP tools. Mitigation: public-address validation, scheme restrictions, redirect denial and response limits.
- **high** — DNS rebinding between validation and connect. Residual risk in `src/modules/agent/infra/adapters/tool_executor.py` requires connection pinning hardening.
- **high** — process-local rate limits under horizontal scale. Residual risk requires a shared limiter or deployment constraint.
- **high** — browser cancellation not persisted. Required evidence: streaming integration test ending in cancelled trace state.
- **high** — stale or masked test debt. Mitigation: plain pytest gate after transition-test retirement.
- **medium** — multiple Alembic heads. Mitigation: migration workflow requires exactly one head.
- **medium** — schema/model drift. Mitigation: empty-database upgrade and `alembic check`.
- **medium** — worker duplicate consumption. Mitigation: dedicated worker processes and registry ownership.
- **medium** — unbounded provider/tool latency. Mitigation: runtime, HTTP and payload limits.
- **medium** — incomplete execution telemetry. Mitigation: TTFT, total latency, tool and provider event assertions.
- **low** — obsolete migration documentation. Mitigation: current inventories under `specs/execution/inventory/`.
- Evidence paths include `src/shared/workers/`, `src/workers/`, `src/modules/`, `migrations/` and integration tests.
