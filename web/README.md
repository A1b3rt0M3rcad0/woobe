# Quick Start — ProjectRAI Frontend

## Prerequisites
- Node.js 18+
- Backend running on http://localhost:8000

## Setup

```bash
cd web
npm install
cp .env.example .env
```

## Run

```bash
cd web
npm run dev
```

Opens at http://localhost:5173

## Seed demo data

```bash
cd web
npm run seed
```

Login: `customer@gmail.com` / `customer`

## Build

```bash
cd web
npm run build
```

Output in `web/dist/`
