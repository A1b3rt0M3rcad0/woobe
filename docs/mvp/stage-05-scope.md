# MVP Stage 05 scope

- authorized `GET /core/projects/{project_id}/overview` endpoint;
- deterministic metric semantics for empty and partially known data;
- 24-hour, seven-day, and 30-day windows with UTC buckets;
- current release environment classification;
- recent releases and terminal traces;
- knowledge and tools summaries;
- explicit unavailable capabilities instead of fabricated dashboard data;
- constant query count, indexes, query-plan evidence, and performance acceptance;
- backend contract and integration tests.
