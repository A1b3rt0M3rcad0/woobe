## CI failure follow-up

The owner reported three failing checks after local Overview validation. The failures had two separate causes:

- **Acceptance and Container quality:** the independently built Embed imports `woobe-ui` font and token CSS, but its Dockerfile copied only Embed and Runtime client sources. A build using exactly those source inputs failed with `ENOENT` for `woobe-ui/src/styles/fonts.css`. Copying the shared UI package into the builder fixes that dependency without coupling Embed to the frontend. The isolated-input build and the native Docker builder stage both pass. The Acceptance workflow subsequently completed successfully on GitHub.
- **Frontend:** the pinned Chromium 136 runner reports webfont families as `Inter (Fontations)`. Four typography tests required the literal name `Inter`, despite CDP reporting custom-font origin and painted glyphs. The diagnostic run completed 118 browser checks and failed these four font probes. The shared font-evidence helper now removes only the known ` (Fontations)` metadata suffix. It still checks the expected family, web/system origin and positive glyph count, and serif probes still reject interface fonts. Regression cases use the actual CI metadata and reject wrong families, unrecognized suffixes, system substitutions and zero glyphs. Both production and shared-component probes use the same helper.

CI now emits individual Playwright failure annotations and retains browser reports/traces for seven days. This exposed the precise font-probe errors through GitHub's web interface while the environment's REST API destination remained blocked. The original passing local run used system Chromium 154, so it did not encounter the pinned runner's family-name annotation. Source declarations and actual font files did not change in this follow-up.

Additional local evidence includes 122 production-browser checks and 252 shared-component/overlay checks with Georgia excluded through a command-scoped Fontconfig profile, followed by five font-evidence regression cases, four final production-font probes and a final shared-primitives probe with strict system Georgia enabled. Embed unit tests/typecheck, the independent builder and workflow lint also passed. These local browser runs used system Chromium and system FFmpeg; they do not replace the final pinned GitHub runner result. Detailed commands, original run links and capture-time qualification are in `validation.json`.
