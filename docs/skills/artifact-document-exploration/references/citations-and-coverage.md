# Citations and coverage

Use the complete source reference from `woobe_artifact_read`. Preserve its
Artifact ID, revision ID and locator; a citation to a mutable path alone is not
reproducible. If a read returns several locators, attach the locator for the
passage that supports each claim rather than citing a neighboring heading.

Search results and structural outlines help choose what to read. They do not
establish that a document is complete, that every matching passage was indexed,
or that a generated summary is literal source text. State partial or missing
coverage from processing metadata when it affects the answer. A missing result
means only that the current authorized catalog/index did not return a match.

For tables, keep headers attached to row values. For a figure, cite the exact
page/region if available and separate visible labels from interpretation. When
the source map is absent, OCR is missing, or a table cannot be read reliably,
report the gap and avoid invented page numbers, row values, or quotations.

For comparisons, record the exact revisions read from both sources. Explain
whether a difference is a direct contradiction, different scope/date, or an
inference. Do not turn repeated statements from one source into independent
corroboration.
