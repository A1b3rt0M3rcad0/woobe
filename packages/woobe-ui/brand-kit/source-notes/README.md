# Materiais originais x reconstituições

1. As imagens em `reference-boards/` são a reprodução integral do material aprovado.
2. As imagens em `raster-extractions/` são recortes reais dos boards, sem corrigir textos, cores ou dimensões.
3. Os SVGs da marca foram traçados a partir do board fornecido.
4. Os componentes UI em SVG são reconstituições programáticas editáveis.
5. O pacote deliberadamente não contém fontes em binário.
